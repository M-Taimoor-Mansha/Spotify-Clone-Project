# 🎵 Spotify Clone

A modern Spotify-inspired music streaming application built to replicate the core user experience of Spotify. This project features a clean and responsive interface, seamless music playback controls, playlist management, and an intuitive user experience.

## Features

* User authentication
* Music playback controls
* Playlist creation and management
* Search and browse functionality
* Responsive design for desktop and mobile devices
* Modern Spotify-inspired UI

## Tech Stack

* HTML
* CSS
* Javascript

## Purpose

This project was built to strengthen my full-stack development skills and gain hands-on experience with modern web technologies, state management, authentication, API integration, and responsive UI design.

## Disclaimer

This project is intended for educational and portfolio purposes only. It is not affiliated with, endorsed by, or connected to Spotify in any way.
